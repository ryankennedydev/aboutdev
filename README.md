# AboutDev

AboutDev is a modern web platform created to help developers discover useful tools, frameworks, libraries, and learning resources for their projects.

The project was built with **React** and provides a clean, interactive interface with categorized resources and an About page.

## Technologies

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Running Locally

```bash
npm install
npm run dev
```

Then open the local URL displayed in the terminal.
