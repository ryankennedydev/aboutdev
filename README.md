# AboutDev

AboutDev is a modern web platform designed to help developers discover useful tools, frameworks, libraries, and learning resources for their projects.

It offers a clean and interactive interface where users can explore categorized developer resources and learn more about the platform through a dedicated About page.

## Features

* Explore tools and resources for developers
* Categorized content for easier navigation
* Modern and responsive user interface
* Dedicated About page
* Clean design focused on usability

## Technologies

This project was built with:

* React
* Vite
* Tailwind CSS
* React Router
* Lucide React

## Running Locally

Clone the repository:

```bash
git clone https://github.com/ryankennedydev/aboutdev.git
```

Navigate to the project folder:

```bash
cd aboutdev
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL displayed in your terminal.
